Learning Log — 9 november 2026

1. Wat is een source hosting platform en welke heb ik gekozen?

Een source hosting platform is een plek waar je de code van je website online kunt opslaan en beheren. Ik heb gekozen voor GitHub. Hier staat mijn repository met alle bestanden van mijn Digital Garden. Via GitHub Pages kan ik mijn website ook online publiceren.

2. Welke domeinnaam heb ik gekozen en hoe heb ik die gekoppeld?

Ik heb gekozen voor de domeinnaam **marouasworld.nl**. Deze heb ik via TransIP gekoppeld aan GitHub Pages. Hiervoor moest ik de DNS-instellingen aanpassen en mijn domeinnaam toevoegen bij de instellingen van GitHub Pages.

3. Hoe maak ik aanpassingen aan mijn website en hoe publiceer ik deze?

Ik gebruik VSCodium om mijn website aan te passen. Hiervoor open ik het index.html bestand en verander ik de HTML-code. Daarna sla ik mijn wijzigingen op en maak ik een commit via Source Control. Vervolgens klik ik op 'Sync Changes' om de wijzigingen naar GitHub te sturen. GitHub Pages zorgt er daarna voor dat mijn aangepaste website online komt te staan.

In het begin lukte het mij niet om mijn wijzigingen op de website te zien. Uiteindelijk kwam ik erachter dat ik mijn wijzigingen nog moest synchroniseren met GitHub. Nadat ik dit had gedaan, verscheen mijn aangepaste titel wel op de website.
