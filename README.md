Bi-weekly Geek 1 - Wat is het internet dan?
Tijdens de eerste Bi-weekly Geek hebben we stilgestaan bij hoe het internet werkt, wie het internet beheert en hoe afhankelijk we zijn van commerciële bedrijven.

**Responsive design**

- max-width: voorkomen dat content te breed wordt op grote schermen.

- CSS Grid: content verdelen over meerdere kolommen.

- auto-fit: automatisch het aantal kolommen aanpassen aan de beschikbare ruimte.

- minmax(): een minimale en maximale grootte voor kolommen bepalen.

- Media queries: de vormgeving aanpassen vanaf een bepaalde schermbreedte.

**Check out**

1. Leg uit wanneer een website 'lelijk' wordt en geef voorbeelden van wat je kunt doen om deze onderdelen te verbeteren.

Een website kan lelijk worden wanneer de vormgeving niet goed meeschaalt met het scherm. Bijvoorbeeld wanneer teksten te breed worden, afbeeldingen niet goed passen of er te veel lege ruimte ontstaat. Je kunt dit verbeteren door gebruik te maken van CSS Grid, media queries en een maximale breedte voor bepaalde onderdelen.
